# ACCEPTANCE — 统一验收与测试矩阵

两个实现使用相同操作系统、Chrome 版本、测试素材、网络环境与测试步骤。仅使用本人或授权内容；不在资料包内保存视频、Cookie 或账号凭据。

| ID | 场景 | 通过标准 |
|---|---|---|
| A01 | 安装 | Chrome 开发者模式直接加载扩展，不需 Python/Docker/本地服务 |
| A02 | 视频页 | Popup 识别当前单视频并显示准确标题 |
| A03 | 首页/搜索页 | 显示“此页面没有可下载的内容～”，无有效下载按钮 |
| A04 | 图文页 | 不进行图片下载，显示无可下载视频 |
| A05 | 视频资源解析失败 | 与非视频页区分，显示解析失败/重试提示 |
| A06 | 文件大小可获取 | 显示真实大小，单位格式一致 |
| A07 | 大小无法获取 | 显示“大小未知”，但可用资源仍允许下载 |
| A08 | 下载点击 | 只有用户点击圆形按钮时才触发下载 |
| A09 | 选择保存 | 弹出 Chrome 原生另存为对话框，可更改路径及文件名 |
| A10 | 用户取消保存 | 无虚假完成消息，重新打开插件后可再次下载 |
| A11 | 下载成功 | 文件存在、可播放，且由实际下载完成事件确认 |
| A12 | 下载失败 | 提供明确失败/重试反馈，不误报成功 |
| A13 | Popup 失焦关闭 | 实际后台下载不会仅因 Popup 消失而错误终止 |
| A14 | 视觉 | 名称、主色 #FF2442、圆形按钮、标题及大小满足规格 |
| A15 | 功能边界 | 无图文下载、跨作品批量、会员、账号与后台爬取 |
| A16 | 安全 | 不采集或上传凭证/浏览历史，权限和外联有说明 |
| A17 | 水印结果 | 逐条记录样本是否有水印，绝不以单一结果泛化 |

## 统一样本建议
- 自有或授权的公开视频若干（建议 10–20 条，涵盖不同视频时长与页面类型），记录链接标识、是否登录、预期与结果。
- 两个无视频场景：小红书首页和搜索页；一个图文笔记。
- 人工模拟无网络/失效资源；用户主动取消保存。

## 输出证据
每项记录 Pass/Fail/Blocked、实测步骤、截图或日志位置、Chrome/系统版本、版本提交 SHA。不要把猜测或 UI 模拟当作通过。对于因平台或环境导致无法验证的场景标记 Blocked。
