# UI-SPEC — Popup v1.0

## 布局
Chrome 浏览器工具栏点击后原生 Popup，建议宽约 340px，自动适配内容高度。顶部 Logo/自绘下载图标 + “RED 视频下载助手”，可有低对比版本号。中心是视频标题及操作提示，主要操作是直径约 136px 的圆形下载按钮；底部辅助说明。不得浮夸宣传或冒充官方。

## 视觉 Token（建议）
- 主色：RED 红 `#FF2442`；背景白 `#FFFFFF`，轻暖白 `#FFF9F7`。
- 正文：`#262626`；辅助文字中性灰 `#777777`；弱分割线 `#EEEEEE`。
- 整体轻量，少装饰，适度圆角；不要使用之前的偏 B 站粉色 `#E97892`。
- 优先系统字体/本地字体，不引入远程字体依赖。

## 有视频状态
标题最多约两行，超长截断但应能看到完整标题（例如 tooltip）。提示：“当前视频已就绪，点击即可保存”。圆形按钮依次显示下载图标、“下载”、大小（例如 16.06 MB；未知时“大小未知”）。点击前仅展示，不自动下载。

## 状态文案
| 状态 | 主提示 | 行为 |
|---|---|---|
| 检测中 | 正在识别当前页面… | 避免可点的假按钮 |
| 视频就绪 | 当前视频已就绪，点击即可保存 | 显示可用下载按钮 |
| 非视频页面 | 此页面没有可下载的内容～ | 提示打开单篇视频笔记 |
| 解析失败 | 暂时无法识别这个视频 | 给出刷新或重试指引 |
| 调用下载/等待用户选路径 | 请选择保存位置 | 不提前标记完成 |
| 下载中 | 正在下载… | 可以参考浏览器下载状态 |
| 下载成功 | 下载完成 | 以真实下载完成事件为准 |
| 下载失败 | 下载失败，请重试 | 有可靠错误原因则展示 |
| 用户取消 | 已取消保存 | 恢复就绪，不能显示“失败”或“完成” |

注意：Chrome 的 Popup 在失焦时可能关闭，不应假设保存文件对话框关闭后原 Popup 仍存在；下载状态须在独立后台维护。取消保存的可观测性取决于 Chrome 下载事件，需进行真实测试。
