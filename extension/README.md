# RED 视频下载助手 — P1 最小验证版

非官方工具，仅用于在**本人或已授权**的小红书视频作品上验证"点击插件 → 原生另存为保存当前视频"的技术路径。纯浏览器扩展，无需 Python/Docker/本地服务。

## 安装（Chrome 开发者模式）

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车。
2. 打开右上角「开发者模式」开关。
3. 点击左上角「加载已解压的扩展程序」，选择本目录（`extension/`，即包含 `manifest.json` 的文件夹）。
4. 工具栏出现「RED 视频下载助手」图标即安装成功（若被折叠，点击拼图图标将其固定）。
5. 要求 Chrome 111 或更高版本（使用 MAIN world 内容注入）。

## 使用方法

1. 在 Chrome 中打开**单个小红书视频作品页**（网址形如 `www.xiaohongshu.com/explore/xxxx` 或 `/discovery/item/xxxx`）。
2. 点击插件图标打开 Popup：
   - 视频页：显示视频标题和文件大小（取不到时显示「大小未知」，仍可下载）；
   - 非视频页（首页/搜索页/图文页等）：显示「此页面没有可下载的内容～」；
   - 页面数据无法解析：显示「暂时无法识别这个视频…」，可刷新页面后点「重试检测」。
3. 点击红色「下载」按钮 → 弹出 Chrome 原生另存为对话框，选择位置与文件名后保存。
4. 状态文字如实反映：下载中… / 下载完成 / 已取消保存（取消不是失败）/ 下载失败（含原因）。
5. 下载由浏览器原生完成，Popup 关闭不影响下载；重新打开 Popup 会与真实下载状态对齐。

## 本地代码检查

```bash
cd extension && node tools/check.js
```

校验 manifest 合法性、JS 语法、禁止依赖（GM_*/WebSocket/服务端调用）、关键需求特征（MAIN world、saveAs、状态同步等）。

## 已知限制（P1 边界）

- 未做实机验证：本阶段只完成了静态实现与本地代码检查；T01–T13 需人工在真实 Chrome + 授权样本上执行。
- 文件大小取自页面数据 `video.media.stream` 的 `size` 字段，与 originVideoKey 直链实际大小可能有偏差；不做网络探测。
- 仅支持 `www.xiaohongshu.com/explore/` 与 `/discovery/item/` 两类视频页；`rednote.com` 域名暂不支持。
- 极简 UI（非正式 RED 风格）；不支持图片、批量、账号、转码/去水印处理。
- 视频直链可能有时效：识别与下载之间不要间隔过久；失效时刷新页面重开插件。
- 未登录状态下页面数据是否完整未经测试（TECHNICAL.md 实验项 E5）。

## 许可与安全

- 本扩展为原创代码，未复制 GPL 参考项目的代码（参考结论仅使用 URL 格式、JSON 字段路径等事实性信息，见工程 `TECHNICAL.md`）。
- 不读取、保存 Cookie；不收集浏览记录；仅请求 `activeTab`、`scripting`、`downloads`、`storage` 与小红书域宿主权限；仅由用户点击触发下载。
